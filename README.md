## What I'm building

- **Spoki MCP**: one remote MCP server (`https://mcp.spoki.com/v2/mcp`) that lets ChatGPT, Claude, Cursor, VS Code and n8n work inside a Spoki account. Listed in the Official MCP Registry as `com.spoki/mcp`. [Docs](https://support.spoki.com/en/docs/integrations/get-started-with-spoki-mcp/)
- **Spoki for Claude Code**: plugin with tools, skills and agents for WhatsApp messaging, contacts, campaigns and automations. [Repo](https://github.com/Spoki-App/spoki-claude-plugin)
- **Spoki for Cursor / Grok Bot**: marketplace plugin on top of the remote Spoki MCP server. [Repo](https://github.com/Spoki-App/spoki-cursor-plugin)
- **Spoki Voice**: an AI voice agent that answers business calls and continues the conversation across channels. [Launch](https://x.com/Spokiapp/status/2070091583278436465)
